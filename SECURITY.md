# Security

**Please do not report security problems in public issues.** Use GitHub's private reporting
instead: [Report a vulnerability](https://github.com/Vanixxx/owncryptofolio/security/advisories/new)
(tab *Security* → *Report a vulnerability*). Only the maintainer sees the report.

owncryptofolio is a hobby project maintained in spare time: there is no fixed response time,
but security reports come first. Fixes go into the next release; the
[changelog](CHANGELOG.md) names them.

Supported is the latest release only — update to it before reporting.

Good to know when running it: owncryptofolio is built for the home network. Put a VPN or a
reverse proxy with HTTPS in front of it for access from outside; never expose port 8080 to
the internet directly.

---

**Sicherheitslücken bitte nicht als öffentliches Issue melden**, sondern über die private
Meldung von GitHub: Reiter *Security* → *Report a vulnerability*. Nur der Betreuer sieht sie.
Unterstützt wird nur die neueste Version.
