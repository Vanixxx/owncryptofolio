# Guides

Here are the step-by-step guides: what you enter where, what you click, and what
happens next.

A guide is written once its feature actually works, while using the real interface. A guide
derived from plans describes what should happen, not what does happen. That would not help
you.

## All guides

- **[Installing with Docker](install-docker.md)**: Docker Compose with database, folders,
  update — for any computer with Docker.
- **[Installing and updating on Unraid](install-unraid.md)**: database, template from Apps,
  port 8085, one-click update.
- **[Settings](settings.md)**: appearance, app icon, language and currency, password,
  schedules, prices, tax and head of the reports, blockchain services, Claude and API, backup.
- **[On your phone](phone.md)**: add to the home screen, using the app, on the go.
- **[Build your own integration](build-an-integration.md)**: a new exchange or network as a
  folder, example and checklist.
- **[Troubleshooting](troubleshooting.md)**: page not reachable, database, forgotten password,
  failed fetch, differing balance.
- **[First start and setup](first-start.md)**: setup code (only if needed), password, recovery
  key, basic settings.
- **[Setting up and importing sources](sources.md)**: add an exchange or wallet, API keys,
  fetching, file import, networks without an integration, balance check.
- **[Transactions](transactions.md)**: search and filter, correct, link transfers, mark what
  has no counterpart, enter movements.
- **[Dashboard and holdings](portfolio.md)**: total value, history, result, holdings per coin
  with price chart and average buy price, futures, gaps.
- **[Statistics](statistics.md)**: account health, returns per month and year, comparison in
  BTC, spot and futures balance, fees, income, activity.
- **[Prices](prices.md)**: check the mapping, cross-check, worthless from a date, fetch one by
  one.
- **[Tax report](tax-report.md)**: § 23, § 22, § 20, loss carryforward, Excel/PDF, freezing a
  report.
- **[Source of funds](source-of-funds.md)**: where the money of a sale, transfer or withdrawal
  comes from, for today's holdings and in advance for a planned transaction, as a PDF for the
  bank, notary or exchange.
- **[Backup](backup.md)**: schedule, retention, test restore, restoring.
- **[System status](system-health.md)**: is everything running? Database, backup, fetches,
  prices, storage.
- **[Connect Claude](connect-claude.md)**: let Claude Code or Claude Desktop read your data
  and — after you confirm — edit it (MCP), tokens with a level, home network only.
- **[API (JSON)](api.md)**: your data for a widget, Home Assistant, Excel, scripts; all
  addresses with parameters and examples.

What the terms mean is under
[Concepts](../README.md#concepts--what-the-terms-mean). Those pages are not about how to use
the app but about what things mean.
