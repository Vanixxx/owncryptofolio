# owncryptofolio

English: [en/README.md](en/README.md)

owncryptofolio sammelt deine Krypto-Transaktionen aus allen Quellen an einem Ort: von
Exchanges, aus Blockchain-Netzwerken für deine Hardware-Wallet, aus Excel- und
CSV-Dateien und von Hand. Daraus zeigt es dir, was dein Portfolio aktuell wert ist,
wie viel du eingesetzt hast und wie dein Gewinn oder Verlust steht — und es erzeugt
die Auswertung, die du für die Steuer brauchst.

Es läuft auf deinem eigenen Rechner oder Server. Deine Daten verlassen ihn nicht.

> **Hinweis zum Entwicklungsstand:** Die Software wird laufend weiterentwickelt. Die
> Konzeptseiten unten beschreiben, wie owncryptofolio arbeitet. Eine **Anleitung** wird erst
> geschrieben, wenn die jeweilige Funktion läuft, und zwar an der echten Oberfläche.
